HOW IT WORKS
- public/ = front end. worker/index.mjs = /api/room, one Durable Object per room
  (create/join/invite/edit/new/play/profile/logout). /api/room/ws pushes each member's
  view on every change; phones poll every 15 s as backup (1 s if socket down).
- Rooms private: device token in localStorage ("cw-rooms"), invite links 7 days,
  device-login links 30 min. Opening a room shows a lobby.
- Rules: public/games/ludo.mjs (browser runs it too for instant moves; lib/games/ludo.mjs
  re-exports), lib/games/whot.mjs, crossword lib/generator.mjs + lib/words.mjs.
- Ludo 3D: public/ludo3d.js + public/models/ludo_set.glb (David's Blender model),
  three.js r169 vendored in public/vendor/three. Top-down camera, darker board, dice
  thrown onto the centre, tokens 1.45x. Shows "Loading board…"; flat CSS board only if
  3D fails. Lobby preloads 3D.
- Ludo UI: tap a piece (black ring) → tap a number [die | sum | die] → it moves, ring
  clears. Roll button on your roll.
- Capture effect (public/ludo-fx.js): big random line ("CHOP AM JOORRR!", "Get rekt",
  "Oya go house!"; victim's phone: "Dem don chop you! 😭", "Ouch! Back to yard", "Na wa o!"),
  board shake, confetti in victim's colour, victim token flies/tumbles back to yard (3D),
  victim's phone vibrates (Android). Reduced-motion: text only. Lottie/Rive could replace
  the text later (512×512, transparent, 1–2 s, <150 KB, text as shapes).
- Sounds (public/sound.js): David's recordings in public/sounds/ (Pixabay SFX + their own
  "Chop am joor" / "Oya go house" voice lines), mono 64k MP3, trimmed + loudness-levelled
  with ffmpeg: roll, land, steps (cut to move length), capture, groan, home, turn, win,
  voice-chop, voice-oya. "Get rekt" has no recording → phone's voice. Missing files fall
  back to code-made sounds. 🔊/🔇 by the Ludo status. Add/swap: drop <name>.mp3, list in FILES.
- Vs computer: lobby cards for Ludo and Whot; each engine exports BOT/BOT_NAME/botMove/
  isOver/turnPid and the bot runs on Durable Object alarms, 600 ms apart.
- Game over: full-screen "<name> won" / "Computer won" (public/game-over.js, shared by
  Ludo and Whot). "Play again" restarts the same game straight away; "Other games" = lobby.
- Seats shift along one each new board game (info.round), so colours and who starts
  alternate — you and Mayowa (or the computer) swap red+yellow / green+blue every game.
- Dark mode: follows device; ◐ in top bar cycles device/dark/light.
- Tests: npm run validate (puzzles, generator, Ludo/Whot rules, bot).

HOUSE RULES
- Ludo: two dice, each die used once; 6 brings a token out; ONLY double 6 = roll again.
  Capture: victim → yard, capturing token → straight home, no bonus roll.
  Sum = both dice as one jump (only landing square counts). Token home = no bonus.
  2 players: first member red+yellow, second green+blue, all 8 home to win.
- Whot: 1 hold on, 2 pick two (blockable with a 2, stacks), 5 pick three (not
  blockable), 8 suspension, 14 general market, 20 whot (call shape).
- Crossword: book Puzzle 1 + random puzzles.
